# Asset manifest and sourcing

## Own assets
- Playfair Display via verified Google Fonts CSS at render time — headings and date reveals.
- Manrope via Google Fonts CSS — captions, annotations, axes, and UI.
- All diagrams, timelines, calendars, document vector layout and line treatments: original Curio Bureau JavaScript/Canvas drawing.
- Embedded natural editorial textures procedurally generated; no purchased stock material.
- Natural Earth CC0 public-domain country polygons from https://github.com/nvkelso/natural-earth-vector ; projected with explicit known coordinates.
- Act citation and selective re-typeset document headings from official Samoa Attorney General 2011 act; quote short passages with official credit.
