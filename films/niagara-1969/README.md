# Curio Bureau Episode 003 — The Waterfall They Switched Off

**Subject:** Temporary dewatering of the **American Falls**, Niagara, June–November 1969. The nearby Horseshoe Falls **continued flowing**.

## Editorial source
- `studio/motion.js` — deterministic 64-second Canvas player + WebM export.
- `studio/director.js` — original editorial composition, multi-layer water / geologic systems, maps, timestamps, synced captions, and audio score.
- `studio/film.template.html` — interactive browser player.
- `assets/sfx/*` — **episode-selected** reusable sounds previously obtained from the owner's connected Google Drive; not the whole source library.
- `preproduction/*` — primary sources, visual research, four actual 1080x1920 SVG style frames, storyboards, animatic, 45 timestamped SFX cues, rights and QA.
- `review/*` — actual rendered QA pixel samples, caption SRT and voice pacing evidence, generated by the build.

## Build
Checkout `film/niagara-1969-dewatering` and run:

```bash
npm install
npx playwright install --with-deps chromium
pip install edge-tts==7.2.3
node scripts/prepare-niagara-map.mjs
node scripts/fetch-niagara-photo.mjs
python scripts/synthesize-niagara.py
node scripts/build-niagara.mjs
CURIO_HTML=dist/niagara-1969/Curio_Bureau_Niagara_1969_Editorial.html CURIO_VOICE=dist/niagara-1969/narration.wav CURIO_OUTPUT=dist/niagara-1969/Curio_Bureau_Niagara_1969_Editorial.webm node scripts/render-niagara-webm.mjs
node scripts/render-niagara-master.mjs
```

Headless MP4 master is native 1080 × 1920, 30fps, H264 CRF16 with stereo AAC. Word captions baked into both MP4/WebM. No forced narration tempo. Do not call final before the GitHub production workflow and visual inspection pass.

## Audio
Master uses a genuinely audible original tonal score, noise-synthesized **non-archival** water bed, and 11 actual Drive-sourced samples across 45 editorial events. Track source and rights in `preproduction/sound-cue-sheet.csv`. Automatic loudness aims for integrated -14 LUFS, peak <= -1 dBTP; the final encoded mix must be listened to by a qualified reviewer before describing it as *human-listening verified*.
