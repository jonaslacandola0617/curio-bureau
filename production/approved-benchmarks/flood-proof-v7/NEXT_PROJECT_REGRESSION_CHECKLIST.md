# Curio Bureau: mandatory next-project regression check

Use with the full57-item Sun checklist. This is the added regression gate, not a replacement release checklist. Every result needs actual evidence and a truthful status; no automatic artistic pass from this document.

## Before designing

- [ ] Read current root instructions, episode CURRENT, approved flood playbook, Sun and four-test approvals; record relevant source commits.
- [ ] Identify latest selected topic and scope. Historical captions/candidates do not commission an episode.
- [ ] Declare `sun-disappeared-v1`, `image-owned-editorial-v1`,12fps authored scenes/camera and30fps native1080×1920 output. Keep exact ending30fps.
- [ ] Separate directly observed facts, owner reports, calculations, operator estimates, official guidance, hypotheses and proposals. Keep missing values unknown.
- [ ] Gather source-specific real records where appropriate, permissions/provenance and component-resolution limits. Label conceptual models honestly.

## Before moving composition

- [ ] Every scene names proposition, viewer-before/after, visual operation, invariant, initial/difficult/resolved states, assets/masks/anchors, next inheritance, truth boundary and caption clearance.
- [ ] Show high-quality demanding art across opener, mechanism, evidence qualification, hardest intermediate and payoff; no quality drop after the first shot.
- [ ] Compare to approved Concrete v2, Diomede v2b, Shrimp v2, Brine v2b and flood V7 at matching viewing size. Record exactly which actual assets were viewed.
- [ ] With narration/headings hidden, the source/components still express the relationship. Retain necessary factual labels during this check.
- [ ] Separate photographic/evidence planes have purposeful motion. Geographic/source coordinates remain registered. Camera reveals information rather than merely drifting.
- [ ] Caption, label and platform-control clearance hold at the key event, not only in final stills.

## Before native capture

- [ ] Meaningful changes about every1.5–2s; explicit timecoded reasons for longer holds. Caption changes/noise/drift do not count.
- [ ] Flat backing; assembled art/source optics; separate static paper; moving foreground soft-light grain; protected captions/wordmark; exact ending bypass.
- [ ] Grain clearly changes photographic/map pixels and full-frame image areas. Negative-space noise is insufficient.
- [ ] Paper has its own visible material structure and independent control; no cloudy background substitute.
- [ ] Motivated focus hunts settle sharp. Selective blur and luminance share the intended attention field.
- [ ] Applicable motion integration/chromatic behavior/jitter/exposure/ink/edge treatment have named windows and exclusions; no blur/shadow haze behind type.
- [ ] Native capture entry point invokes finishing, standard and audit validators. Proof hashes match actual source/config/timeline.
- [ ] Same-time native per-effect A/B, constant-source temporal grain, caption-core protection and ending protection recorded.
- [ ] Natural Bernard speed1; actual speech drives edit; score evolves; existing catalogued sounds map to real editorial/action events. No false field-sound claim.

## If artwork is locked and only finishing is requested

- [ ] Freeze exact approved baseline; preserve sources, crops, labels, type, motion, camera, optics, parallax, timing and all audio.
- [ ] Normalize only the permitted finishing hook; original scene renderer remains equal.
- [ ] Test no-paper/no-grain native equality at demanding states across all scenes.
- [ ] Original encoded audio packets and timing identical; original native ending frame hashes identical.
- [ ] No new art, voice, music, source or ending regeneration.

## After encoding

- [ ] Archive each complete movie immediately with source/version/bytes/SHA256/URL. Archive closed expensive chunks at least every two.
- [ ] Download and match full bytes/hash; strictly decode the entire movie. Partial transfer is not automatically a render defect.
- [ ] Inspect actual encoded phone-size picture across all scenes and worst transitions. Grain and paper survive compression; sources remain readable and focus settles.
- [ ] Inspect complete ending/tail and captions at actual word events; independent caption-boundary/platform review is distinct from ASR reconciliation.
- [ ] Independently audition actual picture+sound against cue/retention timestamps before claiming listening QA. Mark unperformed checks NOT REVIEWED/PENDING.
- [ ] Save owner visual approval separately from technical, listening, rights and publication statuses. Do not publish without authorization.
- [ ] Assess reach/retention only with real matched-age24-hour/seven-day values, denominators and reporting windows. No fabricated threshold, causal verdict or guaranteed virality.
