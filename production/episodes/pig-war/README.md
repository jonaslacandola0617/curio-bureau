# Pig War episode adapter

This adapter preserves the existing full-film choreography. `style.js` defines its selected colors, `map.js` its sourced map representation, `scenes.js` its authored shots and camera/objects, `data.py` its geography/timing loading, and `audio.py` its score and cue direction. Shared drawing, typography, focus, finishing, player and audio operations live in `production/engine`.

`episode.json` identifies the private image/font/data/audio inputs. Point the CLI at the original private project root with `assets/` and `baseline/SFX_CUE_SHEET_R2.json`. No private bitmaps, texture files, narration audio or embedded HTML are committed here.

The engine's verification record describes exact sample comparisons against the current original project. The posted film's caption phrase timings remain machine-aligned/script-reconciled; posting does not constitute independent word-boundary or headphone listening certification. No new film or SFX was generated for this migration.
