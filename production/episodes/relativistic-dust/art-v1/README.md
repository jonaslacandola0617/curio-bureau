# Relativistic Dust — native static art v1

Eight native 1080×1920 static review states and eight counterparts with decorative titles/draft captions hidden. Opening, research evidence, reference-frame initial/intermediate/resolved, contact, crater and conditional protection payoff. Actual speech/timing, motion and movie do not exist yet.

The original AI atlas illustrates an enlarged grain and graphite-like shield. It is not a real interstellar sample, measured crater, flight hardware or validated impact simulation. Surface identity is approximate rather than pixel-registered: future moving assets require separated masks and repaired regions, not an unexplained bitmap crossfade. Native source-cell footprint stays at or below 600px, below the 627px cell width. There is no claim that enlargement creates new detail.

Pinned Playfair900.ttf and Manrope800.ttf are reused by path from the existing black-dwarf art source; no new font binaries redistributed. @napi-rs/canvas uses the existing 0.1.100 pin. The renderer records image/font hashes and dimensions. The workflow preserves output JPGs, contact sheet, manifest and self-contained HTML in this branch.

Static source-local illustration texture and clean labels can be inspected. Temporal overlays, focus hunts, 12fps motion inside 30fps output, independent parallax, actual-word captions, Bernard, score/SFX and exact ending remain pending moving production.
