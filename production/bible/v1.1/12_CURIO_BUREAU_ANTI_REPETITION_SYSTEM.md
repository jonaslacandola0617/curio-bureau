# 12 — ANTI-REPETITION SYSTEM: HOW TO BE CONSISTENT WITHOUT LOOKING IDENTICAL
## Problem from observed episodes
005 reuses the same pale building grid and brown sinusoidal flood across ~37–46s; 006 repeats the same road/facades/H-sign backdrop across ~37–59s; 007 repeatedly falls back to its opening illustration after midsection diagrams. The brand is identifiable, but animation novelty collapses. Consistency belongs in **craft standards and evidence language**, not in repeated scenery or composition template.

## 1. Shot fingerprint ledger
Every shot logs:
`episode / start / end / factual claim / primary family C01–C14 / hero object / camera axis / camera motion / environment ID / background asset ID / transition ID / annotation type / evidence medium / color mode / sound motif / semantic state change / QA status`.

**Near-duplicate rule:** Flag adjacent shots if ≥4 of these five match: (1) shot family, (2) camera scale/axis, (3) main environment, (4) main object orientation, (5) annotation positioning; and no visible new causal state develops. Two consecutive may be allowed for a mechanism; three require documented justification and side-by-side director review.

**Cross-episode duplicate rule:** A signature hero object, transition sequence, or environment asset from a previous film may be reused only for cross-reference with a justified source or relevant geographic continuity; otherwise design anew. E.g., do not repurpose Chicago's abstract ratchet waves as Boston molasses and assume color changes count as novelty.

## 2. Visual Variety Index (VVI), diagnostic not an optimization game
For an episode with N major shots:
- `F = distinct major shot families / max(1, min(N,8))`, capped at 1.
- `C = distinct camera systems / max(1,min(N,5))`, capped at 1. System means fixed photo-macro / macro object / ground level / overhead cartography / cross-section, not tiny pan differences.
- `M = unique subject-owned physical-mechanism actions / max(1,min(N,4))`, capped at 1.
- `D = 1 − (near_duplicate_adjacent_pairs / max(1,N−1))`.
- `E = share of important claims directly visualized with source evidence or true explanation, not only title typography`.
**VVI = 0.20F + 0.15C + 0.25M + 0.20D + 0.20E.** Range 0–1. This is a review cue, not a substitute for creative judgment; a calm emotional hold may be exactly right. Score should prompt conversation, not enforce frantic animation.

## 3. Quality continuity floor
Art complexity is measured at five fixed checkpoints: frame0, 25%, hardest mechanism, 75%, final. Reviewer scores each 0–5 for detailed silhouette, materials/texture, perspective, spatial credibility, and story-specific cues. **No main-shot composite should drop more than 1 point from the opening reference in the same category** unless intentionally minimalist and dramatically justified. Episode 007 fails this qualitative criterion (poster-grade opening / flat mechanical schematics).

## 4. Scene adjacency exercises
Take every six consecutive major shot frames (captions removed). View side by side at 180px width. If they look like a generic web slideshow or if 4+ are the same dark field with a changing heading, rearrange and redesign.

Example re-edit for Sweden 33–55s:
1. External empty street soundscape / low POV under restriction (C04/C01)
2. Ultra-macro mechanical H sign reveal (C03)
3. Clock at 04:50 overlaying a real junction map (C06/C12)
4. Top-down authorized vehicles moving right (C09)
5. Ground-level right-hand traffic resumes at 05:00 (C01)
6. Worker reveals new road marking / archive photo angle (C05)
Current cut reused essentially the same illustrated street and cars as backgrounds. The six-step redesign can keep map orientation consistent while camera, focal scale, material and state progress distinctly.

Example re-edit for Chicago 12–55s:
1. Archival sewer-plan macro (C08)
2. Brick arched sewer section with grade/soil gradient (C02)
3. Exterior shop doorway stranded below new pavement (C09)
4. Macro steel jackscrew bearing rotates under beam (C03)
5. Ground perspective whole storefront frontage rises (C01)
6. Lit interior with shop continuing to operate (C04)
7. Contemporary 1860 lithograph details and source date (C05)
None needs a generic flat title card. All maintain a recognizable source-annotated visual grammar.

## 5. Project-level restrictions
- Never put one full-frame generated image into **three or more separate major acts** to conceal incomplete motion. Separate/deepen/mask/map if reusing a scene as continuity, or create new licensed/source geometry.
- At least **one custom explanatory hero object** must be modeled/drawn at high detail per episode, then used in 2–4 transformed states; this maintains subject specificity.
- At least **one verified archival evidence object** (where historically available and rights-cleared) must influence an animated explanation; if no usable archive, log it and use clearly labeled original reconstruction.
- Each major act should usually change either camera axis, physical environment or evidence medium; do not change all three at once every time or viewer will lose geography.
- No base 'generic map' object without verified geographic data. No more than one repeating generic whoosh. No ambiguous engineered load paths.
- A shared intro/outro is a semantic signal, but logo appears only after story is underway and last 0.8–1.8s.

## 6. Approval protocol
Art director annotates shot ledger `distinct / justified-repeat / harmful-repeat`. A harmful-repeat mark is a P1 remediation task. QA automator can flag exact IDs/treatment equality; a human approves whether causality actually developed. Preserve historical accuracy over artificial variety; never choose a false camera/viewpoint merely to increase VVI.
