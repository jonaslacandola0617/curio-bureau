### Fixed / flexible / prohibited distinction
**FIXED:** palette semantics, type roles, source label language, centered captions, research ethics, timing/QA thresholds, restrained credible editorial tone. **FLEXIBLE:** shot composition, environment accents, animation class, source-material amount, sound motif, lens/angle, topic-specific textures. **PROHIBITED:** recycling exact facades or symbol schemes without topic fit, stickmen/placeholders, bottom captions, repeated empty navy titles, fake public-domain status, logo pre-roll, exporting a '4K' MP4 built from 1080p material.
