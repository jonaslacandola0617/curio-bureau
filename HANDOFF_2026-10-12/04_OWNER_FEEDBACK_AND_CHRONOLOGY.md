## E. Critical lessons learned from the whole failure
1. The most attractive known output were approved static concepts, not any animated Ghost Army video; don't mistake the latter as style anchors.
2. Great images alone still won't satisfy user if connected animation doesn't create visual thought/immersive storytelling.
3. More motion effects, 3D parallax, script, SFX, font choices, 4K format, or source photograph provenance do not automatically create attractive sequences.
4. Built-in rendering capability can be preserved, but animated objects and artwork need independent semantic layers and complete designed intermediate frames.
5. Storyboard evolving transformations and camera/graphic relationships FIRST, commission layer-ready source artwork SECOND, art-direct all motion, THEN export.
6. Evidence-first map and data graphics have a place, but avoid generic infographics as a replacement for documentary spectacle.
7. Iteration requires actual visual peer review and ability to reject internally; don't send the user more objectively weak clips asking “is this closer?”
8. User has supplied sufficient reference evidence. Respect fatigue. No further guidance interrogation.
